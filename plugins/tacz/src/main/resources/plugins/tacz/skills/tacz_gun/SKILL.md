# Skill: tacz_gun

装了 TACZ 之后,**你的身体认识 TACZ 枪**——它把枪当成真正的远程武器。打怪时直接走原来的战斗命令,
身体自己会拿枪、走位、瞄准、开枪、拉栓、换弹、开镜,不用你操心。`tacz.gun` 组里的函数是精细控制:看枪、换枪、试枪。

## 清怪 / 遭遇战 / 跟随警戒:用 numen.fight.attack(自动用枪)

```lua
numen.fight.attack(foe)      -- 一场仗:自己走位、自己开枪、打死为止
numen.fight.clear()          -- 清掉附近所有敌对生物
```

有枪时身体自动:拉开距离开枪(喷子近、狙击远)、挑能开火的枪、拉栓/换弹/开镜全自动。
**回执会说"是我用枪打的、开了几枪"**——打完之后你就知道你开过枪、怪是你打死的,别以为怪"自己死了"。

**自主开火**:你什么都不派,被怪盯上、怪进了枪的射程,自卫本能也会自动接管用枪还手——跟随、挖矿、
走路时都一样,打完自动回到原来干的事。**没有视线不会开枪**:看不见目标时它会先走到看得见的地方,不对墙空射。

## 打一个具体目标(牛、羊、天上飞的、任何有权限的目标):用 tacz.gun.shoot

```lua
local foes = numen.scan.entities("all", {radius = 24})
tacz.gun.shoot(foes[1])      -- 原地瞄准打一发(你站在原地,打不打得着看距离和视线)
```

它自己把枪摆对:拉栓、换弹(带着匹配弹药才换得起来)、狙击枪开镜、等冷却、站定。
**没视线会明确失败并提示你换位置**——先 `numen.scan.sight` 看、`numen.move.to` 走过去,再打。
打出去返回 `result = "success"`;没子弹、没枪都会说清原因。

## 看枪、换枪、试枪

```lua
tacz.gun.options()           -- 装了哪些枪、手上拿的哪把、弹匣/膛内/换弹/拉栓/冷却状态
local o = tacz.gun.options()
tacz.gun.equip("tacz:ak47")  -- 换枪:拿背包里另一把(枪 id 从 o.guns 里照抄)
tacz.gun.fire()              -- 朝面朝方向试一枪:试枪用 fire,打怪用 shoot/attack
```

换弹/拉栓/开火模式/开镜的精细控制: `tacz.gun.reload()`、`tacz.gun.bolt()`、`tacz.gun.fire_select()`、
`tacz.gun.aim(true/false)`——平时用不上,shoot 和 attack 都替你做了。

**注意:客户端设置里的"自动换弹"对你无效**——你没有客户端,换弹永远靠 shoot/attack 自己换。

## 被追着打怎么办

有怪追你,你要还手:直接 `numen.fight.attack(那只怪)`。就算你什么都不做,自卫本能也会在它进射程时自动用枪还手。
先 `numen.status.self()` 看血:血太少(比如 8 点以下)先 `numen.move.flee` 拉开距离再回头打。

## 避免误伤(最重要的一条)

开枪是伤人,**对谁开枪由权限层裁决**:你朝主人的宠物、命名过的动物、或者村民开枪,权限层会拦下来或先问主人。
所以你不要自己判断"这枪能不能打",正常瞄准目标打就行,不该打的自然打不出去。

但你自己也要守两条:
- 开枪前扫一眼 `numen.scan.entities("player", {radius = 16})`,别把主人卷进你和怪之间的弹道。
- 别朝会爆炸的东西(苦力怕)贴脸打——战斗系统自己会保持距离。

## 别做的事

- 手上没枪、背包里没枪就假装开枪
- 没弹药了还一遍遍重试——补弹药、换枪、或换近战(numen.fight.attack 没枪时用剑/拳头)
- 对着墙后的敌人一直射(shoot 会告诉你没视线,先换位置再打)
