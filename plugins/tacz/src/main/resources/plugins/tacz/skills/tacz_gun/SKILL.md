# Skill: tacz_gun

装了 TACZ 之后,**你的身体认识 TACZ 枪**——它把枪当成真正的远程武器。打怪时直接走原来的战斗命令,
身体自己会拿枪、走位、瞄准、开枪、拉栓、换弹、开镜,不用你操心。`tacz.gun` 组里的函数是精细控制:看枪、换枪、试枪。

## 打一个具体目标(牛、羊、天上飞的、任何有权限的目标):用 tacz.gun.shoot

`tacz.gun.shoot` 朝目标**直接瞄准开一枪,任何实体都能打**:牛、羊、鸡、猪、天上飞的都行,
不挑敌不敌对——只受权限层管。**没有距离限制、没有"看不见就不打"的限制**:瞄准就打,
打不打得着由回执告诉你。

```lua
local foes = numen.scan.entities("all", {radius = 24})   -- "all" 扫全部(牛也在里面);天上飞的用 "mob"
tacz.gun.shoot(foes[1])                                  -- 原地瞄准打一发
```

**回执是实话,照它说的理解:**

- `result = "hit"` → 打中了,目标掉血了;
- `result = "killed"` → 这一发把它打死了;
- `result = "missed"` → 子弹打出去了,但没接上:目标可能挪了、超出枪的有效射程、或者中间有东西挡着。
  **这是距离/弹道的事,不是弹药的事——走近几格再打**(numen.move.to 到它附近 10 格内),或者再打一发。
- 其他结果(no_ammo / not_gun)照字面理解,照它说的做。

**绝不要自己推断"弹药不匹配/枪没伤害"**:子弹确实打出去就是 hit/missed/killed,弹药状态看
`tacz.gun.options().fireable`。你开枪造成伤害这件事是真实的。

打天上飞的东西:**站在原地就能打**,不用走过去。

## 清怪 / 遭遇战 / 跟随警戒:用 numen.fight.attack(自动用枪)

```lua
numen.fight.attack(foe)      -- 一场仗:自己走位、自己开枪、打死为止(打天上的也照打)
numen.fight.clear()          -- 清掉附近所有敌对生物
```

有枪时身体自动:拉开距离开枪(喷子近、狙击远)、自动挑能开火的枪、拉栓/换弹/开镜全自动。
**回执会说"是我用枪打的、开了几枪"**——打完之后你就知道你开过枪、怪是你打死的,别以为怪"自己死了"。
被怪追时自卫本能也用枪还手,回执同样会告诉你。

## 看枪、换枪、弹药

`tacz.gun.options()` 一次给你:

- `guns`:装了哪些枪的 id 清单;
- `carried`:你背包里带着的几把枪,每把按它自己的 id 列出来;
- `fireable`:**现在能开火的几把**(弹匣有弹,或你带着它的匹配弹药)——判断"有没有弹药"只看这里,别猜;
- 主手拿的是哪把、弹匣几发、膛内子弹、换弹/拉栓/疾跑/冷却状态。

```lua
tacz.gun.equip("tacz:ak47")   -- 换枪:拿另一条的 id(喷子换狙、狙换喷子都是这个动作)
```

## 试枪 / 朝面朝方向开一枪(不需要目标)

```lua
tacz.gun.fire()   -- 朝你面朝的方向打一枪,试枪响不响。打怪用 shoot/attack,试枪用 fire。
```

## 打中立生物/村民/宠物:权限会问主人

默认规则下,打**没名字、没主人的野生动物**直接放行;打**有名字的、有主人的(宠物)、村民**,
权限层会**先问主人**,主人没点头你不会开枪——这是规矩,不是故障。你调 shoot/attack 之后
主人会收到询问,等他答复;别反复重试同一只。

## 跟随 + 警戒(边跟边打)

主人让你跟着他时,直接派跟随就行。路上有怪盯上你、进了枪的射程,**自卫本能会自动接管**:
停下、开枪、解决,然后**自动回到跟随**——不用你安排,这是本能。打完回执会告诉你用枪打了几发。

## 被追着打怎么办

有怪追你,你要还手:直接 `numen.fight.attack(那只怪)`;就算你什么都不做,自卫本能也会在它进射程时
自动还手。先 `numen.status.self()` 看血:血太少(比如 8 点以下)先 `numen.move.flee` 拉开距离再回头打。

## 避免误伤(最重要的一条)

开枪是伤人,**对谁开枪由权限层裁决**:你朝主人的宠物、命名过的动物、或者村民开枪,权限层会拦下来或先问主人。
所以你不要自己判断"这枪能不能打",正常瞄准目标打就行,不该打的自然打不出去。

但你自己也要守两条:
- 开枪前扫一眼 `numen.scan.entities("player", {radius = 16})`,别把主人卷进你和怪之间的弹道。
- 别朝会爆炸的东西(苦力怕)贴脸打——战斗系统自己会保持距离。

## 别做的事

- 手上没枪、背包里没枪就假装开枪
- 打不中就脑补"弹药不匹配/枪没伤害"——missed 就是没打中,走近换位再打;弹药看 options().fireable
- 没弹药了还一遍遍重试——补弹药、换枪、或换近战(numen.fight.attack 没枪时用剑/拳头)
