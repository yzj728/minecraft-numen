# Skill: tacz_gun

装了 TACZ 之后,`tacz.gun` 组里的函数能让你拿枪、开枪、朝面朝方向开枪、换弹、切开火模式、开镜。
每个怎么写,用 `numen.api.help("tacz.gun.shoot")` 查;这里只讲什么时候用、怎么连起来用。

## 先看手上和包里有哪几把枪

`tacz.gun.options()` 一次给你:
- `guns`:这台机器装了哪些枪的 id 清单。
- `carried`:**你背包里真实带着的几把枪,每把按它自己的 id 列出来**(主手、副手、背包都算)。
  喷子和狙是两条不同的 id——切换武器就是拿另一条的 id 去 equip。
- 主手拿的是哪把、弹匣几发、膛内子弹、换弹/拉栓/疾跑/冷却状态。

**平时不用盯着状态**——`tacz.gun.shoot` 会自己把枪摆对。清点装备、换枪时看 `options()`。

## 拿枪、换枪

```lua
tacz.gun.equip("tacz:ak47")
```

枪 id 从 `options().guns` 或 `options().carried` 里照原样抄。换枪就是 equip 另一条的 id——
喷子换狙、狙换喷子都是这个动作,两把枪的 id 不同,不存在"两把是一样的"。

背包里没有会明确失败——那是真的没有,去跟主人要,别反复试同一把。

## 识别敌人

```lua
local foe = numen.scan.entities("hostile", {radius = 24})[1]
```

每个结果是实体,带 `id`、`type`、`pos`、`distance`、`hp`。挑最近的一只,记得它的 `id`。

## 开枪:站在哪就在哪打,不用先走过去

枪是远程武器,**shoot 不走路、不量距离**。正确流程很简单:

```lua
tacz.gun.equip("tacz:ak47")      -- 1. 拿上枪
local shot = tacz.gun.shoot(foe) -- 2. 直接打
```

**别先 move。** shoot 自己会处理一切:

- 手动枪膛空 → 自己拉栓再打
- 弹匣空 → 自己换弹(前提是包里带着对应弹药)
- 没切枪 → 自己切
- 狙击枪 → 先开镜再打(之后连打保持开镜)
- 冷却/换弹/拉栓中 → 等完再打
- 疾跑中 → 自己站定
- **身体会转向目标**——枪口朝哪,子弹往哪(和原版弓战斗同一套转向)
- **开火期间战斗与逃跑本能让开**——哪怕有僵尸正在追你,这一枪也打得出去,不会打到一半乱跑

打出去返回 `result = "success"`;开不了会明确说为什么:

- **"no line of sight"**:看不见目标(有墙挡着)。这时才动位置:
  ```lua
  local s = numen.scan.sight(foe)   -- 看是什么挡着
  numen.move.to(foe.pos, {arrive = "near", range = 12})  -- 绕过去/走近点
  -- 到了再 shoot 一次
  ```
- **"no ammo"**:包里的弹药打完了,跟主人要弹药或换枪。
- **"no gun / not_gun"**:手上没枪,先 equip。

**连发**:自动枪连打几发,就调几次 `shoot`,每次一发,等每次返回再调下一次。
**边打边动**:一枪打完想换位置,再 `numen.move.to` 走位,然后继续 shoot——移动和开枪交替进行。

## 试枪 / 朝面朝方向开一枪(不需要目标)

```lua
tacz.gun.fire()
```

**这个不需要目标**,朝你面朝的方向打一枪:试枪响不响、放空枪都行。子弹沿当前视线飞,
不会自动瞄准、也不看前面有没有自己人——**打怪用 shoot,试枪用 fire**。

## 换弹 / 开火模式 / 开镜(精细控制用)

```lua
tacz.gun.reload()        -- 手动换弹:只"开始",换没换完看 options().reloading
tacz.gun.bolt()          -- 手动拉栓:shoot 已经替你拉,这是精细控制用
tacz.gun.fire_select()   -- 单发/全自动/连发之间轮换
tacz.gun.aim(true)       -- 开镜(减散布,可选;狙击枪 shoot 会自动开)
tacz.gun.aim(false)      -- 收镜
```

**注意:客户端设置里的"自动换弹"对你无效**——你没有客户端,换弹永远要靠 `tacz.gun.reload()` 或 `shoot` 自己换。

## 被追着打怎么办

有怪追你,而你要用枪还手:直接 `shoot` 就行——开枪期间自卫本能让开,不会和你抢身体。
打之前用 `numen.status.self()` 看血:血太少(比如 8 点以下)先 `numen.move.flee` 拉开距离,
再回头打,别和僵尸贴脸换血。

## 避免误伤(最重要的一条)

开枪是伤人,**对谁开枪由权限层裁决**:你朝主人的宠物、命名过的动物、或者村民开枪,权限层会拦下来或先问主人。
所以你不要自己判断"这枪能不能打",正常瞄准目标开枪就行,不该打的自然打不出去。

但你自己也要守两条:
- 开枪前扫一眼 `numen.scan.entities("player", {radius = 16})`,别把主人卷进你和怪之间的弹道。
- 别朝会爆炸的东西(苦力怕)贴脸打,站爆炸波及范围之外再打。

## 别做的事

- 手上没枪、背包里没枪就假装开枪
- 看得见目标却先长途跋涉走过去——枪不用贴脸,原地打
- 同一只打不动的目标反复调 shoot——看失败原因,没弹药就是没弹药,没视线就换位,换办法(近战/换枪/要弹药)
- 把开枪当成唯一手段:近处、弹药不足时,用 numen.fight.attack 近战更省
