# Skill: tacz_gun

装了 TACZ 之后,**你的身体认识 TACZ 枪**——它把枪当成真正的远程武器。这意味着打怪时
直接走原来的战斗命令就行,身体自己会拿枪、走位、瞄准、开枪、拉栓、换弹、开镜,不用你操心。
`tacz.gun` 组里的函数是精细控制:看枪、换枪、试枪。

## 战斗:直接用 numen.fight.attack

```lua
local foe = numen.scan.entities("hostile", {radius = 24})[1]   -- 识别敌人
numen.fight.attack(foe)                                        -- 打它(有枪就会用枪打)
```

**有枪时身体会怎么做**(全自动,不用你下额外指令):

- 自动拉开距离(和弓战斗同一套走位环),**不会贴脸切刀,也不会乱跑**;
- 自动把枪拿到手上、转向目标——枪口朝哪,子弹往哪;
- 手动枪自动拉栓、弹匣空自动换弹(前提是包里带着对应弹药)、狙击枪自动开镜;
- **被怪追时自卫也是用枪打**——逃跑链认得枪,不会再把你当赤手空拳;
- 打空弹药而包里没有对应弹药时,这场仗会失败并说明原因:补弹药、换枪,或改用近战。

连打几只: `for _, foe in ipairs(numen.scan.entities("hostile", {radius = 16})) do numen.fight.attack(foe) end`
(或直接用 `numen.fight.clear()`)。

## 看枪、换枪

`tacz.gun.options()` 一次给你:

- `guns`:装了哪些枪的 id 清单;
- `carried`:**你背包里带着的几把枪,每把按它自己的 id 列出来**——喷子和狙是两条不同的 id;
- 主手拿的是哪把、弹匣几发、膛内子弹、换弹/拉栓/疾跑/冷却状态。

换枪就是拿另一条的 id 去 equip:

```lua
tacz.gun.equip("tacz:ak47")
```

枪 id 从 `options().guns` 或 `options().carried` 里照原样抄,别凭印象猜。背包里没有会明确失败——那是真的没有,去跟主人要。

## 试枪 / 朝面朝方向开一枪(不需要目标)

```lua
tacz.gun.fire()
```

**不需要目标**,朝你面朝的方向打一枪:试枪响不响、放空枪都行。它不会自动瞄准、
也不看前面有没有自己人——**打怪用 numen.fight.attack,试枪用 fire**。

## 精细控制(一般用不上,shoot 会替你全做)

```lua
tacz.gun.shoot(foe)      -- 原地朝一只实体开一枪(战斗用 numen.fight.attack 更好:它会自己走位)
tacz.gun.reload()        -- 手动换弹:只"开始",换没换完看 options().reloading
tacz.gun.bolt()          -- 手动拉栓
tacz.gun.fire_select()   -- 单发/全自动/连发之间轮换
tacz.gun.aim(true)       -- 开镜(减散布,可选;狙击枪战斗时会自动开)
tacz.gun.aim(false)      -- 收镜
```

**注意:客户端设置里的"自动换弹"对你无效**——你没有客户端,换弹永远靠战斗系统或 `reload` 自己换。

## 被追着打怎么办

有怪追你,你要还手:直接 `numen.fight.attack(那只怪)` 就行——自卫链和这场仗认识枪,会用枪打。
先 `numen.status.self()` 看血:血太少(比如 8 点以下)先 `numen.move.flee` 拉开距离,再回头打,别贴脸换血。

## 避免误伤(最重要的一条)

开枪是伤人,**对谁开枪由权限层裁决**:你朝主人的宠物、命名过的动物、或者村民开枪,权限层会拦下来或先问主人。
所以你不要自己判断"这枪能不能打",正常瞄准目标打就行,不该打的自然打不出去。

但你自己也要守两条:
- 开枪前扫一眼 `numen.scan.entities("player", {radius = 16})`,别把主人卷进你和怪之间的弹道。
- 别朝会爆炸的东西(苦力怕)贴脸打——战斗系统自己会保持距离。

## 别做的事

- 手上没枪、背包里没枪就假装开枪
- 没弹药了还一遍遍重试同一场仗——看失败原因,没弹药就是没弹药,补弹药/换枪/换近战
- 把开枪当成唯一手段:近处、弹药不足时,没枪就只能近战(numen.fight.attack 没枪时用剑/拳头)
